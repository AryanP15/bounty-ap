# BountyAgent (bounty-ap)

> Autonomous AI-Powered Solana Blinks for Community Micro-Bounties. Built for the Colosseum Hackathon.

## 🚀 Overview
BountyAgent streamlines open-source contribution and community task delegation by turning natural language prompts into executable, embeddable Solana Blinks. Contributors can view micro-bounties, review specifications, and claim tasks directly from their social feeds without navigating away.

## 🛠️ Tech Stack
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Icons & UI:** Lucide React, TypeScript
* **Web3 Integration:** Solana Actions & Blinks Specification
* **Deployment:** Vercel

## 📂 Project Structure
* `src/app/page.tsx` — Main dashboard containing the AI Synthesizer, Parsed Schema builder, Social Action container, Active Bounties feed, and Agent telemetry logs.
* `src/app/api/actions/claim/route.ts` — Functional Solana Action backend endpoint handling claim state and transaction payloads.
